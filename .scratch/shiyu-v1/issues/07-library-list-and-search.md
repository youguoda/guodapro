# 07 — 管理窗口：列表与搜索

**What to build:** 用户点击托盘图标，打开完整的**管理窗口**，浏览全部历史条目，并用关键词搜索找回很久以前复制的内容。可在窗口内重新复制任意条目、删除单个条目、按时间段批量删除、一键清空全部历史。

管理窗口服务的是每周数次的"翻检整理"，因此可以大、可以久留、可以有筛选器——与每日数十次的快速粘贴场景截然不同，二者刻意分为两个入口。

历史**绝不整体加载进内存**，一律按需查询。这是"占用内存小"在本模块的具体含义。
