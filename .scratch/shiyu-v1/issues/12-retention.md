# 12 — 保留策略：原图过期清理

**What to build:** 超过保留期的图片原图被自动清理，用户的磁盘占用因此保持有界。条目与缩略图不受影响，历史列表依然完整。

文本、链接、文件路径类条目**永久保留，永不清理**——它们体量小，且是用户日后真正会去搜索的内容。清理只针对图片原图。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 超过保留期的图片原图被清理
- [ ] 清理后条目仍在、缩略图仍在，列表不出现空洞
- [ ] 文本类条目永不被清理，无论多久之前
- [ ] 保留期可配置，修改后对既有数据按新设定生效
- [ ] 清理作业不阻塞界面，也不在用户操作时造成卡顿
- [ ] 应用长时间未运行后再启动时，积压的过期数据能被正确清理
- [ ] 清理过程中断（如强制结束进程）后重启，数据保持一致，不出现指向已删文件的条目
