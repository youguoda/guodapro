# 11 — 标签与置顶

**What to build:** 用户可以给条目打标签（按项目、按用途）、按标签筛选，并把高频使用的条目置顶，让它们始终优先出现。

**已知产品风险**：手工维护标签体系普遍难以长期坚持。本票只交付手工能力，缓解手段（请 agent 建议标签）在 13 中交付。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 可给条目添加与移除标签
- [ ] 一个条目可有多个标签
- [ ] 可按标签筛选，并与其他筛选条件组合
- [ ] 可将条目置顶与取消置顶
- [ ] 置顶条目在列表与快速条中均优先出现
- [ ] 删除标签时，被打过该标签的条目本身不受影响
