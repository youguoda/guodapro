# 04 — 徽标：判定与显示

**What to build:** 用户复制一段英文句子后，光标附近出现一个小**徽标**，一两秒后自动淡出。复制代码、文件路径、URL、纯数字或中文时，徽标不出现。徽标不夺走焦点，用户在原应用中的选区与光标位置不受影响。

徽标本身不显示译文，只表示"这段内容可以翻译"。本票中点击徽标可暂不产生实际效果。

**关键不变量：条目的写入发生在过滤之前。** 过滤器只决定徽标弹不弹，绝不决定记不记——被过滤掉的内容**仍然**产生条目。搞反会让历史出现空洞。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 复制英文自然语言句子时徽标出现
- [ ] 复制代码、文件路径、URL、纯数字时徽标不出现
- [ ] 复制中文时徽标不出现
- [ ] 被过滤掉、未弹徽标的内容**仍然**产生了条目（须有独立测试）
- [ ] 徽标出现在复制发生的光标位置附近
- [ ] 在多显示器、各屏缩放比例不同的环境下，徽标位置与尺寸均正确
- [ ] 徽标置顶显示且不接受激活，出现后原应用的选区与焦点不变
- [ ] 徽标在设定时间后自动淡出
- [ ] 语言检测使用轻量方案，不引入模型
