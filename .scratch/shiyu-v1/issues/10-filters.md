# 10 — 多维筛选

**What to build:** 用户在管理窗口中按日期范围筛选、按内容类型（文本 / 图片 / 链接 / 文件路径）筛选，并能把这些条件与关键词搜索组合使用，从而精确锁定目标——例如"上周复制过的那张图"。

**Blocked by:** 07, 09

**Status:** ready-for-agent

- [ ] 可按日期范围筛选
- [ ] 可按内容类型筛选
- [ ] 筛选条件可与关键词搜索组合
- [ ] 多个筛选条件可同时生效
- [ ] 可一键清除全部筛选条件
- [ ] 筛选结果为空时有明确提示，而非一片空白
- [ ] 组合筛选在大规模历史下依然迅速
