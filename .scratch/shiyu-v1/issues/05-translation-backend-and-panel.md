# 05 — 翻译后端与面板

**What to build:** 用户点击徽标，面板展开，译文逐字流式长出，首字很快到达，用户全程在阅读而不是在等待。面板中同时显示原文以便对照，可一键复制译文，可切换翻译方向，按 Esc 关闭。

翻译后端是**可插拔接口**，本票交付其首个实现（复用用户已有的云端凭据）。接口从第一版就是流式的——事后将流式塞进阻塞式接口是代价极高的重构。

后端提示词必须强制"只输出译文"。通用大模型默认会**加戏**：附加解释、给出多个版本、把一个词扩写成一段。这是缺陷，需有测试覆盖。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 点击徽标展开面板，译文以流式逐步呈现
- [ ] 面板置顶且不接受激活，展开后原应用的选区与焦点不变
- [ ] 面板同时显示原文与译文
- [ ] 可一键复制译文
- [ ] 可在面板内切换翻译方向
- [ ] 按 Esc 关闭面板
- [ ] 流在中途中断时，已到达的部分保留在界面上，并给出明确错误提示
- [ ] 后端超时有确定行为，不会让面板永久停在加载态
- [ ] 后端返回夹带解释或多版本的"加戏"输出时，测试能够捕获
- [ ] 翻译后端是可替换的接口，调用方不依赖具体实现
