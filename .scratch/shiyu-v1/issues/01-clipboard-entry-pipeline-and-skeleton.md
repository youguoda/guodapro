# 01 — 剪贴板条目管道与应用骨架

**What to build:** 用户复制一段文字后，它被记录成一条**条目**并持久保存；重启应用后条目仍在。托盘区出现拾语图标，菜单中能看到最近几条记录。

这是本项目的第一条完整路径，它顺带确立此后所有开发所依赖的结构：Core 作为唯一被测对象、Platform 作为封装操作系统交互的端口、伪造 Platform 驱动测试、存储使用真实 SQLite。**这张票写下的测试将成为此后所有测试的范式，其写法值得额外斟酌**——项目此前没有任何 prior art。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 复制一段文本后，产生且仅产生一条对应的条目
- [ ] 条目记录了内容、来源应用、创建时间
- [ ] 应用重启后历史条目完好
- [ ] 连续快速复制多次，每一次都产生独立条目，无丢失无重复
- [ ] 复制与上一条完全相同的内容时的行为有明确定义并被测试覆盖
- [ ] 托盘图标常驻，菜单可查看最近条目、可退出应用
- [ ] Core 不直接调用任何操作系统接口，全部经由 Platform 端口
- [ ] 测试通过伪造 Platform 驱动 Core，断言数据库中的真实状态
- [ ] 存储层测试使用真实 SQLite（临时目录或内存库），不使用替身
