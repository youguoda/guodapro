# 09 — 图片条目：缩略图与拖拽另存

**What to build:** 用户复制图片后它被记录成条目；管理窗口的列表中直接显示缩略图，用户一眼就能认出是哪一张，不必逐个打开。用户可以把图片条目直接拖到资源管理器，保存成文件。

图片条目保存两份数据：缩略图**永久保留**（因此历史列表永远完整、不出现空洞），原图另存于磁盘并设有保留期。

由于原图本就以文件形式存在，拖放只需拖一个已存在的文件路径，无需实现虚拟文件机制。

**Status:** ready-for-agent

- [ ] 列表中显示图片缩略图
- [ ] 缩略图生成不阻塞界面，复制大图时界面不卡顿
- [ ] 可将图片条目拖到资源管理器并保存为文件
- [ ] 拖放产生的文件内容与原图一致
- [ ] 原图已过保留期被清理后，条目与缩略图仍在，列表不出现空洞
- [ ] 此时尝试拖放会给出可理解的提示，而非静默失败
