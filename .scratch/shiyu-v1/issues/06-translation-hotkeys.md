# 06 — 翻译热键：划词与逃生口

**What to build:** 两条显式触发的翻译路径。其一，用户在任意应用中选中文字后按热键，直接得到译文面板——这让用户读网页、PDF、聊天记录时不必先复制。其二，用户按下**逃生热键**，强制翻译当前剪贴板内容，不论徽标此前是否出现过。

逃生口是自然语言过滤器误判时的唯一兜底。没有它，用户无法区分"过滤器判断失误"和"程序出故障"。

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] 选中文字按划词热键后，面板展开并流式显示译文
- [ ] 取词失败时给出明确提示，而非静默无反应
- [ ] 取词失败后原剪贴板内容完好
- [ ] 划词动作不在历史中留下条目
- [ ] 按逃生热键后，当前剪贴板内容被翻译并展示，不论徽标此前是否出现
- [ ] 逃生口对被过滤器挡下的内容同样有效
- [ ] 前台窗口为管理员权限进程时，划词无法取词，此时给出可理解的提示而非看似崩溃
