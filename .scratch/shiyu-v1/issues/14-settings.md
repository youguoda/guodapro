# 14 — 设置界面与开机自启

**What to build:** 用户在一个克制的设置界面中调整：热键、母语与目标语言、翻译后端与凭据、图片原图保留期、排除规则、开机自启、数据库位置。拾语默认开机自启——托盘常驻工具不自启等于没装——但用户可以关掉。

**设置项刻意保持克制**：不做主题、不做皮肤、不做高级参数面板。设置项越少，"小而精美"越可信。

**Blocked by:** 03, 06, 08, 12

**Status:** ready-for-agent

- [ ] 可自定义全部热键；与已有软件冲突时明确提示并允许改选
- [ ] 可设置母语与目标语言
- [ ] 可配置翻译后端与凭据；凭据不以明文显示在界面上
- [ ] 可设置图片原图保留期
- [ ] 可查看与编辑排除规则，包括预设项
- [ ] 可开启与关闭开机自启，设置与系统实际状态始终一致
- [ ] 可更改数据库位置；**选中会被云同步的目录时必须明确警告**
- [ ] 设置变更即时生效，无需重启应用
- [ ] 界面中不存在主题、皮肤或高级参数面板
