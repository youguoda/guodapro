# 13 — agent 动作：对选中条目执行

**What to build:** 用户在管理窗口中选中一条或多条条目，交给 agent 执行一个**动作**——总结、合并成笔记、改写、建议标签——结果以流式呈现。这让用户查完资料后能直接得到整理结果，也让标签不必全靠手工维护。

**贯穿全项目的原则在此必须成立：只有用户明确选中的内容会被送出，未选中的永不外送。** 不存在任何自动的、后台的、逐条的处理。

动作复用 05 建立的流式后端接口，不另开一套。

**Blocked by:** 05, 07

**Status:** ready-for-agent

- [ ] 可在管理窗口中选中单条或多条条目
- [ ] 可对选中内容执行总结、合并成笔记、改写、建议标签
- [ ] 结果以流式呈现
- [ ] 建议的标签可一键采纳，也可逐个取舍
- [ ] 未被选中的条目内容不出现在任何对外请求中（须有测试）
- [ ] 不存在任何后台自动触发的对外请求（须有测试）
- [ ] agent 未运行或不可达时，给出明确提示，且应用其余功能全部正常
- [ ] 复用 05 的流式接口，不另写一套调用与错误处理
