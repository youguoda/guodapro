# 26 — 快速条并入窄条

**来源：** UI 报告 §5.4；优化报告 O-38；ADR-0012 第 8 条
**Blocked by:** 21
**Status:** ready-for-agent

**What to build:**
- **先测门槛：** 开启轻量模式时，窄条冷呼出 P95 与快速条对比（各 50 次，结果记在本票）。
- **达标：** 合并为一个表面。
  - 快速粘贴（Ctrl+Shift+V，可选"也用 Win+V"）：窄条以粘贴模式出现在光标旁，粘贴后消失、失焦即消失；
  - 打开窄条（Ctrl+Shift+B）：常驻模式。
  - "快速条"作为名词退役，删除 `QuickBarWindow`。
- **不达标：** 保留 `QuickBarWindow` 作为快速粘贴的轻量实现，但改名"快速粘贴"，共用窄条的搜索框、行模板、编号粘贴和键帽。
- 快速粘贴用键盘呼出时，锚到文本插入符（`GetGUIThreadInfo`），取不到再退回鼠标；失焦只隐藏，不把焦点拽回原应用。

**验收：**
- [ ] 门槛数据记录在本票
- [ ] 设置和托盘里只剩一个名词
- [ ] Ctrl+Shift+V → 打字过滤 → Enter，粘贴落在原应用的插入点
