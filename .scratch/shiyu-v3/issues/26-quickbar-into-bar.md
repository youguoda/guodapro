# 26 — 快速条并入窄条

**来源：** UI 报告 §5.4；优化报告 O-38；ADR-0012 第 8 条
**Blocked by:** 21
**Status:** ready-for-agent

**What to build:**
- **先测门槛：** 开启轻量模式时，窄条冷呼出 P95 与快速条对比（各 50 次，结果记在本票）。
- **达标：** 合并为一个表面。
  - 快速粘贴（Ctrl+Shift+V，可选"也用 Win+V"）：窄条以粘贴模式出现在光标旁，粘贴后消失、失焦即消失；
  - 打开窄条（Ctrl+Shift+B）：常驻模式。
  - "快速条"作为名词退役，删除 `QuickBarWindow`。
- **不达标：** 保留 `QuickBarWindow` 作为快速粘贴的轻量实现，但改名"快速粘贴"，共用窄条的搜索框、行模板、编号粘贴和键帽。
- 快速粘贴用键盘呼出时，锚到文本插入符（`GetGUIThreadInfo`），取不到再退回鼠标；失焦只隐藏，不把焦点拽回原应用。

**验收：**
- [x] 门槛数据记录在本票
- [ ] 设置和托盘里只剩一个名词
- [ ] Ctrl+Shift+V → 打字过滤 → Enter，粘贴落在原应用的插入点

## 门槛测量（2026-10-01，工具 `tools/probes/measure-cold-summon.ps1`）

方法：轻量模式开（默认即开）。冷呼出 = 全新探针进程经 `SHIYU_PROBE_CMD` 的第一次
呼出——轻量策略下每次呼出都从零重建，首次呼出还多付一次窗口构造，是诚实的最坏
情形。计时 = 进程启动前一刻 → 宽度（384/460 DIP）+ pid 找到可见窗口，12 ms 轮询；
隔离数据目录 `%TEMP%\shiyu-probe-run\qb26-cold-*`；各 50 次，整个测两遍取后：

| 遍 | 面 | min | P50 | P95 | max |
|---|---|---|---|---|---|
| 1（预热） | 快速条 | 752 | 775 | 832 | 934 |
| 1（预热） | 窄条 | 770 | 800 | 853 | 1240 |
| **2（取后）** | 快速条 | 765 | 798 | **924** | 980 |
| **2（取后）** | 窄条 | 794 | 827 | **887** | 982 |

**判定：P95 差 = 窄条 887 − 快速条 924 = −37 ms（两遍分别 +21 / −37 ms），均远在
100 ms 门槛内 → 达标，走合并路径。** 单位 ms，同一台机器连测，两表面同一测法。
