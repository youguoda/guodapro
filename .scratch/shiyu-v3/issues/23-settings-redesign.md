# 23 — 设置窗重设计

**来源：** UI 报告 §3.9、§5.1、§6.3、U-14、U-15、U-26；优化报告 O-21、O-33；样稿 `docs/review/mockups/settings.png`

**What to build:**
- **窗口：** 系统窗框 + Mica（按票 19 的 spike 结论），880 × 640，左导航 240（宽度 < 760 时收成图标条）。
- **五页加关于：** 常规 / 窄条 / 记录与隐私 / 翻译 / 快捷键 + 关于（全部设置项的归属见 UI 报告 §5.1）。设置项 Id 不变；深链只按 item Id 定位，旧页 Id 走别名表。
- **`SettingsCard` / `SettingsExpander`：** 标签与说明同列（不截断）；控件列右对齐；数值带单位；所有说明都渲染（包括翻译方式的隐私告知）；子项缩进。
- **即改即生效：** 去掉"保存 / 关闭"底栏；数值和文本在 Enter 或失焦时合法才生效；错误显示在出错的卡片内。
- **控件：** 开关用 `ToggleSwitch`；语言用下拉（首项"自动检测"）；动作清单改为可拖动排序、带开关的列表；快捷键用 `KeyCapRecorder`（录制时即时校验冲突与注册失败）。
- **关于页：** 品牌头、"检查更新"按钮、"复制版本信息"（不含个人数据）、打开日志目录、隐私说明。
- **排除规则三层：** 内置清单（只读 chip）、我的排除（从正在运行的应用添加）、高级规则（折叠）。
