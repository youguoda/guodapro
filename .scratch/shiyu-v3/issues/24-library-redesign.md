# 24 — 管理窗重设计

**来源：** UI 报告 §3.8、§6.4、§6.5、U-12、U-13；优化报告 O-34；样稿 `docs/review/mockups/library.png`
**Blocked by:** 19
**Status:** ready-for-agent

**What to build:**
- **窗口：** 系统窗框，1100 × 640；宽度 ≥ 960 时双栏，更窄时单栏。
- **头部：** `SearchBox`，所有筛选以 token 形式进入搜索框；「筛选」弹层（类型、日期快捷项、子类型、标签）；计数显示"筛选数 / 总数"。
- **命令栏**（取代底部两行按钮墙，后者现在已经互相重叠）：
  - 左侧：复制、置顶、收藏、标签 ▾；分隔；删除（只有图标）。
  - 右侧「⋯」：备注、归组、AI 处理 ›、全选、键位速查；最底下是危险组（按时间段删除…、清空全部历史…，Danger 色）。
- **列表与详情：**
  - 列表：日期分组头；文本行 56、图片行 72；选中 = `Selected` 底 + 指示条。
  - 详情：未选中时显示空态；单选显示元信息、正文（散文用比例字体）、属性区；多选显示批量面板（动作带条数）。
- **反馈：** 撤销条浮在列表左下（5 秒，悬停暂停），取代被遮挡的 `StatusLabel`。
- **确认：** 危险操作按分级走 `ContentDialog`，默认焦点在「取消」（替换 6 处 `MessageBox`）。
- **键盘模型：** Ctrl+F、↑↓、Enter 复制、C、P、S、N、G、D/Delete、Z/Ctrl+Z、T 标签、Space 预览、F1 速查、Esc 逐层（UI 报告 §5.2）。

**验收：**
- [ ] 宽 720–1400 之间任意宽度都没有控件重叠
- [ ] 只用键盘完成"搜索 → 选择 → 复制 → 删除 → 撤销"
- [ ] "清空全部历史"不再是一级按钮，并走确认对话框
