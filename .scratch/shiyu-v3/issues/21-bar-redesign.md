# 21 — 窄条重设计

**来源：** UI 报告 §3.1–3.5、§6.1（线框、规格表、状态矩阵）、U-04 至 U-08、U-16 至 U-21；样稿 `docs/review/mockups/bar.png`
**Blocked by:** 14、20
**Status:** ready-for-agent

**What to build:**
- **头部：**
  - 品牌 24 + 搜索胶囊 32 / 16 + "保持在最前"（换成非图钉字形）；
  - 第 2 行：类型分段（accent 字形 + 3×12 指示条，无实心块）、只看收藏（Alt+S）、标签 ghost 下拉（替换 Aero2 ComboBox）、子类型漏斗、✕（只在有筛选时出现）；
  - 命中区 32，字形 16。
- **卡片：** 1 DIP `CardStroke`，圆角 4；四态叠加层；选中 = 2 DIP accent 内环，底色不变；纯文本卡不显示类型，其他类型显示带信息量的标签；两侧栅格对称。
- **托盘：** 叠加在元信息行上，不进布局；节距 32；静止次级色；删除钮静止次级色、hover 转 Danger，前面加分隔线；收藏、置顶按状态换字形；超过 8 枚时收进 ⋯。
- **键帽：** 统一 `KeyCap`；←→ 替换当前选中类型的字形（修好被裁成横线的问题）。
- **双击 = 粘贴**（ADR-0012）。footer 的"撤销"和空状态的"清除筛选"换成家族按钮。

**验收：** UI 报告 §7.1 的 U-04 至 U-08、U-16 至 U-21 逐条像素验收（150% 缩放，浅色与深色主题各一轮）
