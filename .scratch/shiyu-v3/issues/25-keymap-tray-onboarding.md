# 25 — 键位即数据、托盘菜单、引导重做

**来源：** UI 报告 §5.2、§5.3、U-27、U-28；优化报告 O-42
**Blocked by:** 08、23、24
**Status:** ready-for-agent

**What to build:**
- **`KeyMap` 单一来源**（与 `SettingsSchema` 同构）：窄条键帽、管理窗 tooltip、"⋯"菜单加速键列、设置速查、托盘菜单、引导，全部从它渲染。
- **四级教学：** 常显 → 按住 Ctrl / F1 → 同一动作用鼠标触发到第 3 次时一次性提示 → 引导练习。
- **托盘菜单：** 去掉 10 行灰显、点不了的最近内容（共享屏幕时会暴露剪贴板），改为带快捷键的动作菜单（打开窄条、快速粘贴、翻译剪贴板、管理历史、设置、键位速查、检查更新、退出）。
- **引导重做：** 欢迎 → 记录与隐私 → 呼出（键帽录制器，含"也用 Win+V"）→ 翻译（默认自备密钥）→ 试一试（自动打勾的任务清单）。每一步离开时即生效；关闭和跳过都记为已完成。

**验收：**
- [ ] 改一个键，七处同时变（单测：从 `KeyMap` 渲染的各处文本一致）
- [ ] 托盘菜单里不显示任何剪贴板内容
- [ ] 新用户 60 秒内完成引导，并真的用窄条粘贴过一次
