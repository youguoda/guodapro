# 08 — 文件与文件夹条目

**What to build:** 复制文件或文件夹时被记成条目，列表中显示文件名、路径与类型图标；
可以重新复制回剪贴板直接粘贴到资源管理器，可以在资源管理器中定位，
也可以把条目拖回文件系统。复制多个文件时作为一条记录，显示前几项与总数。

## 路径失效是常态，不是异常

文件会被移动、重命名、删除，而条目还留着。**路径失效必须在列表里看得出来**——
参照实现用删除线加淡化表示，并在预览里写明"路径不存在"。做不到这一点，
用户会在粘贴之后才发现东西没了。

文件类型图标按扩展名缓存，不要每次都去问系统——一个装满记录的列表会因此卡住。

钉住）——超大目录不卡不爆库。悬停动作的适用性同步：文件条目出"打开/定位"，
不出"纯文本粘贴"。

**卡片呈现**：文件行 = 扩展名类型图标（`FileTypeIcons` 按扩展名/目录缓存，
SHGFI_USEFILEATTRIBUTES 不需要文件存在）+ 文件名 + 计数尾行；显示行数终于
由密度旋钮"文件条数"控制。**失效路径删除线 + 半透明 + 红字"（路径不存在）"**
——移动/删除过的文件在列表里一眼可辨，不是粘贴后才发现。

**动作**：复制/回车粘贴写回 CF_HDROP（DROPFILES 重建），资源管理器直接粘出
原文件；定位走第一个存活路径；**拖回文件系统**——卡片按住拖出，只带存活
路径（拖不存在的路径只会静默落空）。双侧类型筛选加"文件"项。

**待人工**：在资源管理器选两三个文件 Ctrl+C → 窄条出现文件卡片（图标+名称+

一个源文件后回窄条看删除线与红字。
