# 08 — 文件与文件夹条目

**What to build:** 复制文件或文件夹时被记成条目，列表中显示文件名、路径与类型图标；
可以重新复制回剪贴板直接粘贴到资源管理器，可以在资源管理器中定位，
也可以把条目拖回文件系统。复制多个文件时作为一条记录，显示前几项与总数。

## 路径失效是常态，不是异常

文件会被移动、重命名、删除，而条目还留着。**路径失效必须在列表里看得出来**——
参照实现用删除线加淡化表示，并在预览里写明"路径不存在"。做不到这一点，
用户会在粘贴之后才发现东西没了。

文件类型图标按扩展名缓存，不要每次都去问系统——一个装满记录的列表会因此卡住。
