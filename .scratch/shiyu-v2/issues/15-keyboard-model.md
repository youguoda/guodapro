# 15 — 完整键盘模型与 Escape 层级栈

**What to build:** 窄条主窗完全可以用键盘驱动：上下选择、回车粘贴、
修饰键加回车按纯文本粘贴、数字键直接粘贴第 N 行、空格按住预览、
字母键触发复制/打开/备注/收藏/置顶/删除、左右切换类型、Tab 切换分组、
`Ctrl+F` 聚焦搜索。

**Escape 是一个层级栈，不是关闭键**：按一次退出预览 → 再按清除分组筛选 →
再按清除类型筛选 → 再按才隐藏窗口。

## 为什么 Escape 这样设计

用户按 Esc 时想撤销的是**刚才那一步**，不是整个会话。做成"一按就关"，
用户每次误按都会丢掉正在做的筛选，久而久之就不敢按了——
而 Esc 本该是最没有心理负担的那个键。

## 两处必须让路

- 焦点在输入框里、或存在文本选区时，`Ctrl+C` 应该让给系统的复制，而不是拦下来当条目复制；
- 焦点在输入框里时，左右方向键应该是移动光标，不是切换类型筛选。

这两条不做，用户在搜索框里打字就会不断触发意外操作。
