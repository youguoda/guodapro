# 12 — 常驻窄条主窗与卡片列表

**What to build:** 把管理窗口改造成一个**约 360px 宽的常驻窄条**：无系统标题栏、
置顶、整个背景可拖动、随热键呼出与隐藏。内容是一列卡片——每张有边框与圆角，
上方一行元信息（来源应用图标、类型、时间），下方是内容本体，
右下角是置顶与敏感标记的水印。

顶部是搜索框与分组筛选条，底部是条目计数与快捷键入口。

## 为什么是窄条而不是大窗

它服务的是**每天几十次的快速取用**，不是每周一次的整理。窄条贴在屏幕边缘，
出现与消失都不打断正在做的事；大窗每次出现都是一次上下文切换。

拾语现有的管理窗口（900×620、居中、带标题栏）**保留**，它服务的是另一个场景。
本票新增的是常驻窄条这条入口。

## 密度靠内容截断，不靠改字号

参照实现只提供三个密度旋钮——文本最多几行、图片最大多高、文件最多列几项——
**不提供"紧凑/舒适"模式**。字号与内边距固定，变的只是内容裁剪量。
这让行高可变但可预测，也让界面永远不会在某个密度下显得拥挤或空旷。

### 交付（2026-09-25）

**结构照票 02 的结论落地**：`BarWindow`（360 DIU 固定宽）= 顶部搜索+筛选 →
置顶卡片区（独立非虚拟化列表**堆叠**在滚动区上方，不透出天然成立、零滚动同步）
→ 主列表（`VirtualizingStackPanel` Recycling + 像素滚动 + 1 页缓存，滚动到
底部自动翻页）→ 底部计数与 Esc 提示 + 拖拽改高的把手。卡片=元信息行（16×16
图标/拾字兜底 + 类型 + 时间）+ 内容本体（文本按行数裁剪、图片按高度裁剪）+
右下角"已置顶"水印。全部视觉走票 04 token；呼出=满值直出、隐藏=票 05 淡出。

**热键**：新增第四全局热键（默认 `Ctrl+Shift+B`，设置里可改，四键互异校验）。
**密度旋钮**：文本行数（1~20）/图片高度（40~400）/文件条数（1~10，暂无文件
卡片，票 08 落地后自然生效），保存即 `ApplySettings` 重建生效。**位置持久化**：
移动/改高防抖 800ms 落盘 settings，启动恢复；显示器布局变化导致的位置悬空会
回落到工作区右上。**常驻新鲜度**：可见时每 2 秒对账 `Count()`，有新复制才
整表重建（滚动回顶，已知取舍，票 13 键盘模型时改进为增量插入）。

**实测**：启动 → 复制 → Ctrl+Shift+B → 540×930 物理像素（=360×620 DIU）置顶
