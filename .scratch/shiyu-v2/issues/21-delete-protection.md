# 21 — 删除保护

**What to build:** 收藏与置顶的条目默认不会被自动清理，也不会在批量删除中被误删。
是否保护由设置控制。被保护的条目，**删除入口直接不出现**——
无论是悬停快捷动作还是右键菜单。

## 不显示比禁用更好

被保护的条目如果还显示一个灰掉的删除按钮，用户会反复去点它，然后困惑。
直接不显示，加上收藏/置顶标记本身的存在，用户自己能推出因果。

## 保护的边界要写清楚

保护挡的是**自动清理与批量删除**，不是用户对单条的明确删除意图——
用户取消收藏后仍然可以删。否则会出现"我想删但删不掉"的死角。

**Blocked by:** 10, 13, 19

**Status:** ready-for-human

- [x] 收藏与置顶条目默认不被时间段批量删除影响
- [x] 保护开关可在设置中分别配置
- [x] 被保护的条目**不显示删除入口**，而非显示为禁用
- [x] 取消收藏或取消置顶后，该条目可正常删除
- [x] 清空全部历史时对被保护条目的处理有明确定义并在确认文案中写明

  托盘与右键菜单共用 ActionsFor，一改俱改；键盘 D 在 ExecuteAction 里设防
  （路径没有按钮可隐，守卫替它回答按钮替鼠标回答的问题）。管理窗单条删除

- 收藏切换即时重配托盘（容器订阅卡片 INPC 的 Favorite 变更重跑 PrepareTray，
  指针仍在卡上则保持展开）——否则收藏后旧托盘仍带着删按钮，承诺当场破功。

  再点 ★ 取消 → 8 键（删回归）。
