# 14 — 按住修饰键显示快捷键

**What to build:** 在窄条主窗中按住 `Ctrl`，界面上每个可用快捷键的图标**原地**淡出，
换成一个小圆角徽标显示对应按键——前十行分别显示 `1`–`9` 与 `0`，
搜索显示 `F`，置顶显示 `P`，分组显示 `N`，快捷键面板显示 `K`。松开即复原。

## 这是参照实现里最值得抄的一个设计

它**用零 UI 成本教会用户整套键盘模型**。不需要帮助页，不需要常驻提示条，
不需要用户主动去找——想起来"好像能用键盘"的那一刻按下 Ctrl，答案就在眼前，
而且就在每个功能自己的位置上。

关键在于**徽标与按键处理绑在同一处**。分开写，两者迟早漂移——
界面显示 `P` 而实际按键早就改成了别的，比不显示更糟。

## 一个必须处理的边界

用户按住 Ctrl 的同时窗口失去焦点（比如按了 `Ctrl+Tab` 切走），
此时窗口收不到松开事件，**徽标会永久残留**。参照实现专门处理了这一条。
