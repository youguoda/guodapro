# 13 — 悬停快捷动作与操作反馈

**What to build:** 鼠标悬停在卡片上时，右上角的时间戳让位给一排小按钮——
复制、粘贴、纯文本粘贴、打开、定位、备注、收藏、置顶、删除等，
用户可以在设置里选哪些出现、按什么顺序。移开鼠标，按钮退回、时间戳回来。

操作完成要有反馈：复制成功后按钮图标变成对勾约一秒；可选的提示音。

## 细节决定它像不像一个好工具

- 按钮**挤入而非弹出**：宽度从 0 长到 20px、同时轻微放大与位移，约 160ms。
  弹出会让整行抖动，挤入不会。
- 时间戳**淡出并左移**，按钮**淡入并右移归位**——两者同时发生，读起来是一次交接。
- 每个按钮必须**拦住所有鼠标事件**（按下、点击、双击、中键、右键），
  否则点按钮会连带触发卡片自身的"点击即粘贴"。参照实现在这里拦了六种事件，
  不是多余的。

删除这类不可逆动作在悬停条里出现时要与其他按钮有视觉区分。
