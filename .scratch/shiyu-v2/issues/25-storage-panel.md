# 25 — 存储用量面板与轻量内存模式

**What to build:** 设置里有一处显示拾语实际占用了多少磁盘——数据库、图片原图、
缓存各占多少，以及可以点击直接打开所在文件夹。占用超过阈值时给出提示。

另外：**窗口隐藏后进入轻量状态**，释放不再需要的资源，把后台常驻内存压下去。

## 为什么把这两件事放一张票

它们回答的是同一个用户疑问：**"这个常驻的小工具到底吃了我多少资源？"**
磁盘的答案是一个面板，内存的答案是一个机制。分开做，两边都容易被忽略。

拾语选 WPF 时就明确记下了"常驻内存高于 C++ 方案，量级差异为数十 MB，
这是本次取舍中真实付出的代价"。轻量模式是把这个代价收窄的手段，
也是我们对当初那个取舍的交代。
