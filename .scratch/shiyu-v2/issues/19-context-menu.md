# 19 — 右键菜单

**What to build:** 在条目上右键弹出菜单，包含该条目当时可用的全部动作，
带快捷键提示，支持二级菜单。菜单样式与应用整体一致，**弹出时不夺走窄条主窗的焦点**。

## 为什么不用系统原生菜单

系统的弹出菜单会抢走前台焦点。窄条主窗是个不接受激活的置顶窗口，
一旦焦点被抢走，菜单关闭后窗口可能自动隐藏，用户的操作就断在半路。

参照实现为此把右键菜单做成了一个自己渲染的透明窗口，理由就是这个。
拾语的托盘菜单可以继续用系统菜单（托盘本来就不涉及这个问题），
但**条目右键菜单需要自己做**。

## 可用动作由数据决定

哪些动作出现在菜单里，取决于这条记录是什么类型、有没有备注、是否被保护。
**不可用的动作不显示**，而不是显示成灰的——灰色项在一个十几项的菜单里只会增加扫读成本。

## 实现记录（2026-09-26）

- 自渲染 Popup 而非系统 ContextMenu，理由即票面：系统菜单夺焦，不激活的窄条窗
  在菜单关闭后可能自动隐藏。Popup 不激活任何窗口；本应用 chooser/overflow 同款
  先例，探针实测菜单动作全程窄条可见。
- 菜单项 = `ActionsFor(card)`（与悬停托盘同一份可用性判定，不可用不出现），
  右侧固定列显示按键（C 复制 / Enter 粘贴 / P 置顶 / S 收藏 / N 备注 /
  G 归组 / D 删除；纯文本粘贴、定位无键则留空）。删除项 Danger 色区分。
- 二级菜单：归组 ▸（分组列表 + 未分组 + 管理分组…），悬停展开，选择即归组
  并关菜单。托盘上的「组」按钮仍走选择弹层（可当场新建），两条路径并存。
- 边缘翻转：Opened 后按物理像素实测（Popup 内容 PointToScreen + 工作区
  MonitorFromPoint），越界则在偏移上回推（DIU 换算），逻辑为简单钳制。
- Esc：键盘处理最前先揭菜单（`_cardMenu`/`_cardSubMenu` 任一开着即关并截断），
  再走原有逐层退出栈；点击别处由 StaysOpen=False 关闭，均不触发动作。
- 探针实录（真实右键 + 真实点击）：菜单项及快捷键列齐全（文本卡正确隐藏
  打开/定位）、点「复制」后剪贴板拿到条目原文且窄条可见、二级菜单展开并
  完成「未分组」、Esc 关闭后窄条可见。
