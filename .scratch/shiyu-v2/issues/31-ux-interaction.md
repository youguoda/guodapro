# 31 — 交互体验升级：布局、反馈与可撤销

**What to build:** 落实布局与交互专项分析（2026-09-26 与用户逐条探讨定案）的建议：
窄条动作反馈与可撤销删除、卡片扫读优化、类型分段控件、管理窗双栏、设置窗快捷键
捕获控件、浮层动效与滚动。全部是**交互行为层**改动，与票 30（视觉材质层）正交。

## 已定案的决策（用户逐条拍板，不再讨论）

1. **可撤销删除用 5 秒窗口期**——footer 显示"已删除 · 撤销（5 秒）"，点击或
   Ctrl+Z 恢复。删除前快照整行（文本、标签、分组、备注、收藏、置顶、时间），
   撤销=原样重插（新 id、旧元数据）。管理窗同款。
2. **管理窗双栏撑得起**——≥1280px 窗宽时左列表 + 右详情（完整内容/元数据/动作），
   单击选中即预览、双击才复制；窄屏折回单栏。
3. **"单汉字"保留为拾语的品牌识别元素**——托盘按钮字形化（票 30）后，汉字以
   品牌位保留：键帽徽标（C/O/P/S/N/G/D 已有）、tooltip"汉字+快捷键"、以及
   实施票 30 托盘时的并排视觉对比中给"字形+汉字角标"变体供拍板。**协调点**：
   本条修改票 30 的"托盘按钮从单汉字升级为字形图标"——升级照做，但汉字不退场。

## P0（高价值低成本）

- **动作反馈行**：footer 从静态"共 N 条 · Esc 隐藏"升级为三段式——常态计数、
  动作反馈（"已复制""★ 已收藏""已删除 · 撤销"）、筛选说明（见下）。键盘路径
  （按 C 复制）的视线不在按钮上，footer 是它们的反馈位。
- **footer 计数修正（真 bug，随反馈行一并修）**：`UpdateCount` 恒显全库总数——
  筛选到 3 条时仍显示"共 161 条"。改：无筛选显总数；有筛选显"3 / 161 条"。
- **"Esc 隐藏"文案与 Esc 栈联动（真 bug，一并修）**：有搜索/筛选时 Esc 实际先
  清筛选（BarKeyboard.NextEscape 已算出栈顶），footer 文案应动态跟随——
  "Esc 清除筛选" ↔ "Esc 隐藏"。
- **相对时间**：卡片时间戳改相对（"3 分钟前""昨天"），tooltip 给绝对时间；
  分钟内"刚刚"。窗口隐藏期间不用刷新（Summon 重建时自然更新）。
- **"用过 N 次"移入 tooltip**：正文行让位给内容；N=0 不显示。
- **图片卡统一裁剪比例**：16:10 居中裁剪（UniformToFill + 阴影内裁剪），
  列表行高可预测；预览比例不随原图变化。
- **首用提示**：引导完成后的前 5 次呼出，footer 轮播一次性提示（"悬停卡片或
  按住 Ctrl 查看动作 · Enter 粘贴"）——触发过 3 次动作即停，永不复发。
- **快捷键捕获控件**（设置窗）：点击进入监听态（边框亮起+"按下组合键…"），
  直接按键捕获显示，Esc 取消；替换手打文本框，解析规则复用 HotkeySpec。

## P1（布局级）

- **类型筛选改分段控件**（全部/文本/图片/文件）：四值固定高频切换；←→ 循环键
  保留且当前档可见；子类型收进"更多筛选"溢出；★收藏 toggle 移入搜索框内右侧。
- **筛选 token 化**：筛选生效时搜索框内显示可删 token（`★ · 图片 ×`）——
  "现在为什么只剩这几条"永远可见，× 一键全退。
- **管理窗双栏**（见定案 2）+ **工具栏语义分组**（日常居左、危险居右、间隔符）
  + **批量状态前置**（选中 ≥2 时状态行显"已选 5 条"，批量按钮显影响数
  "批量翻译（5）"；危险按钮按下前数字已看过一遍）。
- **内容层入场动效**（浮层三兄弟）：窗口 Opacity 保持 1（分层窗口合成铁律），
  内部根元素 150ms 0→1 + 8px 上移归位；MotionPlan 减动画时跳过。
- **译文区内部滚动**：ScrollViewer 替换 MaxHeight 截断；流式时自动滚底、
  用户上滚即停。

## 实现记录（2026-09-26，P0 子集）

- footer：CountLabel/FeedbackHost(UndoButton+FeedbackLabel)/SizeGrip 三态；
  计数走 `EntryStore.CountMatching`（BuildFilterConditions 与 Find 共享，
  计数与列表对同一 filter 语义永不分叉）；Esc 提示随 `Filter.IsEmpty` 动态。
- 撤销：删除前 `_store.Get` + `GroupOf` 快照 → footer"已删除「名」· 撤销（5 秒）"
  → 重插走 ImportEntry（标签/分组/备注/置顶/收藏/使用次数全回）；Ctrl+Z 仅在
  撤销窗口期响应。管理窗同款 + **被删图片文件保留至撤销窗口关闭才提交删除**
  （不可恢复的撤销不是撤销），窗口关闭时强制提交。
- 相对时间：Core `RelativeTime`（刚刚/N 分钟前/今天 HH:mm/昨天/N 天前/年内
  MM-dd/跨年 yyyy-MM-dd）；绝对时间+使用次数入时间戳 tooltip；KindText 去掉
  "用过 N 次"。
- 面板：译文区 ScrollViewer（MaxHeight 260，流式距底 24px 内自动跟底）；
  存入历史成功后按钮变"✓ 已存入"置灰，新翻译自动复位。
