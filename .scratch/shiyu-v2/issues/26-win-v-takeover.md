# 26 — 接管 Win+V

**What to build:** 用户可以选择让 `Win+V` 唤起拾语的窄条主窗，**代替 Windows 自带的
剪贴板面板**。默认关闭——这是一个夺取系统按键的行为，必须由用户明确开启。

## 为什么值得做

`Win+V` 是 Windows 用户**已经形成肌肉记忆**的按键。能接管它，意味着拾语不需要
教用户任何新键就能替换掉系统面板；不能接管，用户就得同时记两套。

## 为什么必须默认关闭且能可靠还原

`Win` 组合键无法通过常规的全局热键注册拿到，需要更底层的键盘介入手段。
这类手段有两个必须处理的后果：

1. **拾语崩溃或被强杀时，`Win+V` 必须回到系统行为**，不能把用户的按键永久吞掉；
2. 关闭这个开关后要**立即**还原，不能要求重启。

做不到这两条，这个功能就不该发布——夺走一个系统按键还还不回去，
比不做这个功能糟糕得多。
