# 39 — 窄条布局对标 EcoPaste：双行图标头部 + 大卡列表 + 分组管理 + 现代滚动条

**What to build:** 参照用户提供的 EcoPaste 截图重构窄条（BarWindow），融合用户
2026-09-27 的逐项口头需求。**复用现有全部功能与键盘模型**——本票是布局重构
+ 两处小功能（置顶开关、分组卡片级管理），不是功能重写。

## 第一行（用户逐项指定；2026-09-27 评审定案）

从左到右：

1. **品牌图标（随主题切换，单枚显示）**：浅色主题显示拾语图标、深色主题显示
   深语图标（深色变体），24×24 圆角小图，**同一位置只显示一枚**（评审澄清：
   不是并排两枚）。切换跟随 ThemeManager；两枚资产若缺，先补资产（浅/深各一）
   再接线。
2. **间隔**：弹性空隙分隔品牌区与搜索框。
3. **搜索框（圆角）**：占满中段，圆角 pill 形；框内左侧 🔍 搜索图标
   （E721）+ 占位文字"搜索…"；现有 F 键帽提示保留。
4. **置顶按钮**（新增功能）：搜索框右侧一枚图标钮——
   - 图标随状态切换：置顶开 = E8417（Pin 填充形，accent 色）；关 = E718
     （Pin 常规形，次级灰）；tooltip 写明当前状态。
   - 控制窗口 **Topmost 开/关**（现恒 true）：点击切换，悬浮行为即时生效；
     关闭置顶后窄条不再压住其他窗口。
   - **持久化（评审定案）**：新增 `AppSettings.BarAlwaysOnTop`（默认 true），
     schema 项 `look.bar-topmost`（界面/外观，Toggle）+ SettingsBindings 三件套；
     头部按钮与设置页同源，两处改任一处另一处同步。
   - 与 Esc 退出栈无关（它不是层，是模式）。
   - **z 序验收（评审补）**：关闭置顶后，徽标/翻译面板/预览面板/连接曲线层
     **不得出现孤儿浮层**（面板浮着而窄条被盖）；Win+V 与光标旁呼出路径在
     关置顶态仍可见可用——若浮层家族需要联动降级（如关置顶时预览锚定改为
     短暂置顶），在实现票里写明策略再动。

## 第二行（用户委托设计：尽量图标化）

一行图标工具栏，从左到右分四组（组间细分隔线），全部系统字形
（**字形码定案，与应用既有 IconGlyph 体系对齐；实现时浅/深主题逐枚目检
非豆腐块**）：

1. **类型筛选**（互斥，选中 accent 底——复用 SegmentChip 语义）：
   全部 **E8A9（ViewAll）** / 文本 **E8D2（Font，与"纯文本粘贴"动作同字形，
   语义一致）** / 图片 **E8B9（Photo2）** / 文件 **E8B7（Folder，与"归组"
   动作同字形——场景不同可接受，tooltip 消歧）**；选中项 accent 底 +
   TextOnAccent，未选中次级灰。←→ 循环键保留，键帽徽标保留。
2. **收藏**：★ 单独一枚（现 FavoriteOnly toggle 迁入，**E734** 未选中 /
   **E735** 选中——E735 与收藏动作同字形，一致）。
3. **分组管理**（用户重点，设计见下节）：一枚 **E712（More，横向三点）**
   图标钮弹**分组菜单 Popup**，含：
   - 各分组列表（点击=切换到该分组抽屉，与下行 chips 同步）；**只列未隐藏
     分组**（与 chips 行口径一致，隐藏分组只在管理窗出现）
   - **删除分组**：每个分组项右侧一个小 ✕/🗑 hover 出现 → 确认后删除
     （复用 DeleteGroup，条目回未分组——既有承诺）；**确认条件：任何非空
     分组删除都确认**（不只"当前抽屉恰好是它"）；确认层做在 Popup 内
     原地替换内容（另开窗会因 StaysOpen=false 失焦关闭）
   - **取消卡片分组**：说明——卡片级"移出分组"不在头部，仍在卡片托盘
     「组」按钮弹层（选"未分组"即移出）与右键菜单二级里，头部菜单只管
     分组本体的增删改。菜单尾部两入口：**管理分组…**（打开
     GroupManagerWindow，全部管理能力）与**新建分组**。
4. **子类型筛选**（低频，收进漏斗图标 **E71C（Filter）** 弹层——现
   SubtypeButton 迁入此组）。

**分组行（chips）保留在第二行之下、列表之上**——它是"当前抽屉"的可见
状态；头部图标钮是入口与管理，chips 行是现状指示。两者不重复：chips
只显示分组，不再承担管理。

## 分组管理设计（用户重点，回答"如何删除/取消"）

- **删除分组**：入口收敛到两处——① 分组菜单里每项的 hover ✕（快）；②
  GroupManagerWindow 的删除钮（全功能）。删除 = DeleteGroup，条目回未分组
  （v9 外键 SET NULL 已测试钉死）。UI 上删除钮永远带 tooltip
  "删除分组（条目不删，回到未分组）"。
- **取消卡片分组**：入口保持在**卡片侧**——托盘「组」弹层选"未分组"、
  右键菜单 ▸ 归组 ▸ 未分组。头部不提供"移出"（它操作的对象是卡片，
  不是分组）。
- **心智模型一句话**（写进 tooltip 与 GroupManagerWindow 顶部）：
  "头部管分组本身，卡片管卡片的归属。"

## 卡片（三段式，承票 39 原案）

上行"来源图标 + 类型徽章（图标+文字，含译标）（左）+ 相对时间（右）"；
中行大字号正文（BodyLarge）；图片卡大图档；右下水印保持。选中态 accent
描边 1.5px。**"用过 N 次"计数迁入卡片 tooltip**（现 KindText 承载；类型
徽章不含计数，悬停可见——评审补）。

## 滚动条现代化（用户指定；验收降级定案）

窄条列表滚动条替换默认宽轨：
- 宽 6px（hover 展开到 8px），Thumb 圆角 pill（Radius.Thumb），颜色
  TextTertiary 40% 不透明度，hover 时 60%；
- 轨道透明（无底槽、无两端按钮箭头）；
- **验收口径（评审降级）**：6/8px pill、透明轨道、无箭头按钮为必须项；
  "Overlay 不占布局宽度"（WPF 非原生，需负 margin 类 hack）为尽力项——
  代价大则记为已知差异，不阻塞验收；
- 同一样式应用到管理窗 EntryList 与翻译面板译文区（后者为内建滚动的
  TextBox/TextBlock，模板路径不同，单独验证）。
