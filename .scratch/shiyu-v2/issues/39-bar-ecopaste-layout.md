# 39 — 窄条布局对标 EcoPaste：图标工具栏 + 大卡列表 + 类型徽章

**What to build:** 参照用户提供的 EcoPaste 截图，重构窄条（BarWindow）的布局
与卡片视觉，吸收其四个可迁移的设计决策。**复用现有全部功能与键盘模型**——
本票是布局重构，不是功能增删。

## EcoPaste 截图的设计要点（对标分析）

1. **双行头部**：第一行 = 应用图标 + 居中搜索框 + 收藏 pin + ⋯ 更多；
   第二行 = 图标工具栏（全部/收藏 ｜ 文本/图片/文件 ｜ + 新建）。
   图标钮代替文字下拉，零文字噪音。
2. **内容为主的大卡**：每卡三段式——上行"类型图标 + 类型名（左）+ 时间（右）"，
   中行大字号正文，图片卡直接放大图。卡片间距清晰，圆角 8~10。
3. **类型徽章**：左上小图标 + 类型文字（Files/HTML/Link/Text），一眼分类。
4. **选中态 = accent 描边**（非换底色），右下角别针角标；敏感条目（API key）
   显示打码 + 🔐 角标。

## 拾语的映射（吸收但不照抄）

- **第一行**：搜索框居中放大（现有），右侧 ★ 收藏 toggle（已有）+ ⋯
  （新：收"子类型"弹层入口，替代独立漏斗钮——与现设计合并）。
- **第二行**：现有下划线标签行**替换为图标工具栏**——全部/文本/图片/文件
  四枚系统字形钮（票 30 图标体系），选中态 accent 底；分组 chips 行保留
  KindTab 下划线样式（两层语义不同：图标钮=类型筛选，下划线=分组抽屉）。
- **卡片**：采用 EcoPaste 三段式——上行"来源图标 + 类型徽章文字（含译标）
  （左）+ 相对时间（右）"；中行正文大字号（Body→BodyLarge）；图片卡直接
  大图呈现（ImageHeight 调大档）；右下水印保持（★/分组/置顶）。
- **选中态**：改 accent 描边（现有 IsSelected 触发器已是描边，保留并强化
  描边宽度 1.5）。
- **敏感条目打码**（新增小功能）：内容匹配排除规则的"已记录但需打码"场景
  暂无——本票**只做展示位**（右下 🔐 角标样式定义），打码逻辑依赖后续
  敏感标记票，不在本票实现。

## 不照抄的

- 底部 "6 items" 计数（我们 footer 已有三段式反馈，更强）。
- 图标工具栏里的"+ 新建"（EcoPaste 是收藏夹管理；拾语无此概念）。
- 纯黑背景（我们用 Mica/Acrylic 材质，票 30 已定）。
