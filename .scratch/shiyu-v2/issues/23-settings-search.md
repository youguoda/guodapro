# 23 — 设置内搜索、深链与高亮

**What to build:** 设置窗口顶部有搜索框，输入即列出匹配的设置项，
每条结果标明它在哪个标签页的哪个分区。点击结果直接跳到那一项，
滚动到视野中央，并**播放一段短暂的高亮脉冲**指出"就是这个"。

应用其它位置也能深链过来——比如分组筛选条上的"管理分组"直接跳到分组设置项，
拖入一个备份文件直接跳到导入项。

## 高亮脉冲不是装饰

跳转之后，用户的眼睛需要在一屏几十项里找到目标。没有高亮，
"跳过去了"和"没跳"看起来一样。参照实现用的是三次衰减闪烁而非一次常亮，
因为常亮容易被当成选中态而不是"看这里"。

## 搜索要能搜到用户会用的词

设置的标题往往是产品语言（"保留策略"），用户搜的是自己的话（"多久删"）。
因此每项设置需要**手工写的关键词**，而不是只匹配标题——这是数据树的又一处红利。

## 实现记录（2026-09-26）

- `SettingsSearch`（Core，可测）：标签+提示+手写关键词+页与分区标题全量匹配，
  多词 AND 收窄，上限 12 满额提示"再具体一点"；八测覆盖用户语（多久删/夜间
  模式/误删/迁移）、多词收窄、页区标注、上限、乱词与空输入。
- 界面：设置窗顶部搜索框（占位提示可用大白话搜索），结果覆盖层列出
  标签+「页 · 分区」；点击即 JumpTo：切页 → 滚动到视野中央 → 三段衰减脉冲
  （0.38/0.22/0.12，1.3 秒）指认目标；系统"减少动画"开启时换 1.8 秒静态
  淡染，跳转行为不变。目标被父开关收起时脉冲落在最近可见祖先——不擅自
  替用户改设置值。无结果给"没有匹配的设置项——换个说法试试？"。
- 深链：`SettingsWindow.JumpToItem(id)` 公开；分组管理窗底部「删除保护与备份
  在设置中调整…」（管理窗 → 窄条事件 → App.OpenSettingsAt）为首位消费者。
- 探针实录：输入"多久删"→ 列出"图片保留 · 数据/清理" → 点击 → 跳数据页、
  结果层关闭、目标编辑器滚动到位；乱词给出无结果文案。
