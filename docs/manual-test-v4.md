# 拾语 v3 人工验收清单（票 01–28 的剩余实机项）

> 生成于 2026-10-02。每批约 30 分钟，可分开做；按批次从头到尾即可覆盖 v3
> 全部待人工验收项。已由主控用隔离探针实例自动验收过的项**不在此列**
> （各票内有记录：07-S1、06 崩溃探针、09 端到端与首发验签、11 密钥落盘、
> 18 标题栏字形）。
>
> 通用准备：正常使用中的拾语即可（本清单多数项要在**真实实例**上做）；
> 涉及翻译的批次 C 需要一个自备密钥（设置 → 翻译 → 选服务商预设 → 粘贴
> 密钥 → 测试连接）。

## 批次 A · 数据安全（约 30 分钟）

**A1 覆盖导入失败不动库（票 02）**
1. 设置 → 数据 → 导出备份（不加密），得到一个 `.shiyubk`；记下当前历史条数（管理窗标题栏计数）。
2. 用压缩软件打开该备份，把 `entries.json`（或同名条目文件）改坏（删掉一半字符），保存。
3. 导入这个坏备份，选**覆盖**。
预期：提示导入失败；历史条数、分组、收藏与导入前**完全一致**；图片目录没有多余文件。

**A2 覆盖导入成功并即时生效（票 02 + 07-S3）**
1. 在另一台干净目录（或先导出当前）做一次正常覆盖导入（选含设置的备份，加密或口令均可）。
2. **设置窗全程开着**：导入完成后设置窗各项应自动显示导入的值；再点一次「保存」。
预期：导入的主题/热键/置顶状态保持，保存不回滚（旧版本会把导入结果连同密钥一起冲掉）。

**A3 重跑引导不互踩（票 07-S4）**
1. 设置 → 关于 → 重新运行引导；在引导里改一个热键并完成。
预期：设置窗热键字段即时变新值；新热键立即可用，不需要重启。

**A4 密钥与备份（票 11）**
1. 升级后不重新填密钥，直接翻译一句 → 仍能译（旧明文已自动迁移为加密）。
2. 打开 `%LOCALAPPDATA%\Shiyu\settings.json` 搜密钥前几个字符 → 搜不到（只有 `dpapi:` 开头的串）。
3. 不加密导出备份 → 用压缩软件打开，settings 部分搜不到密钥。
4. 加密导出并勾选「同时导出 API 密钥」→ 再导入到本机 → 翻译仍可用。

## 批次 B · 输入与全局行为（约 30 分钟）

**B1 钩子不再卡输入（票 04，最关键的一项）**
1. 设置 → 快捷键 → 开启「拖选后出翻译徽标」。
2. 连续拖动任意窗口标题栏 20 次。
预期：光标全程无停顿；随后在记事本里拖选一段文字，光标旁仍出现「译」徽标。
3. 开启「接管 Win+V」；先手动复制一段已知文字，再按 Ctrl+Shift+Z 划词翻译。
预期：1 秒后粘贴，得到的仍是自己复制的内容（不是被翻译的选区）。
4. 两个开关各关闭/重开 5 次：无异常无卡顿；退出拾语后 Win+V 与鼠标行为立即还原。

**B2 排除名单拦住划词（票 10）**
1. 设置 → 记录与隐私（或记录页）→ 排除规则里加一个你正开着的应用名（或直接在 KeePass 类应用里做）。
2. 在该应用里拖选一段文字。
预期：不出现「译」徽标；按划词热键则提示一次「前台应用在排除名单里，已跳过取词」。

**B3 危险色与对比度（票 18 余项）**
1. 窄条：悬停任意卡片 → 托盘出现后看最右的删除按钮悬停态。
预期：悬停时删除图标变红（其余按钮保持深灰）。
2. 设置 → 界面 → 主题分段选中项。
预期：选中文字清晰可读（不再发灰发暗）。

## 批次 C · 翻译与网络（约 30 分钟，需自备密钥）

**C1 首用路径全默认（票 08）**
> 建议在另一台机器或暂时清空数据目录做；日常机可跳过，改验 C2。

1. 全新启动走完引导：翻译步默认自备密钥；选「阿里云百炼」预设（自动填好地址模型）；
   点「申请密钥」能打开正确页面；回来粘贴密钥。
2. 「测试连接」分别试：好密钥（成功+用时）、随便改错的密钥（凭据无效）、改错地址（连不上）。
3. 不配置直接「稍后配置」→ 复制一个英文单词 → 点徽标。
预期：面板显示「还没有配置翻译服务」引导卡（**不出现英文异常文本**）；点「去配置」直达预设行。

**C2 日常机验证（票 08/07/13）**
1. 设置 → 翻译：预设下拉选 DeepSeek，确认自动带出 `deepseek-flash`；保存。
2. 管理窗不配密钥时四个 AI 按钮（总结等）应禁用并带说明；配好后启用。
3. 连续翻译两句：第二句首字明显快于第一句（连接复用）。
4. 设置里把「译文语言」改成 English 保存 → 不重启，划词翻译一句中文。
预期：译文立即变成英文。
5. 翻一段很长的文本（约 2000 字）。
预期：完整译完，不在 30 秒处被截断。

**C3 批量翻译报告（票 08）**
管理窗选 3–5 条文本 → 批量翻译。
预期：结束提示「成功 n 条（失败 m 条 + 一句原因）」，不再只有静默计数。

## 批次 D · 服务端（可选，部署公共通道时做，票 05）

部署前按 `server/README.md` 检查清单执行：`IP_HASH_SALT` 已设（不设则 /health 报配置错误）、
DO migration 已跑、**绑定自定义域名**（`*.workers.dev` 在大陆整域不可达）；`npm test` 全绿
（78 个，含语言白名单/IPv6 聚合/限速/原子额度/缺盐 503）。

## 批次 E · 升级到 Release 安装版（约 20 分钟，做完后日常就用它）

1. 从 [Release 页](https://github.com/youguoda/shiyu/releases) 下载 `shiyu-win-x64.zip`，
   解压到 `%LOCALAPPDATA%\Programs\Shiyu`。
2. 退出当前实例（托盘 → 退出），从新位置启动；关于页显示 `0.9.0-rc1`。
3. 设置 → 开机自启保持开启 → 重启电脑（或注销重登）。
预期：自启从新位置启动；`settings.json` 与历史照常。
4. 托盘 → 检查更新。
预期：rc 是预发布，不提示更新（正式版发布后才会提示）。
