# 使用报告 — 本轮 UI 改造后的拾语

**适用版本**：2026-09-26 构建（票 30/31/32 之后）。启动方式不变：托盘图标
或开机自启；窄条 **Ctrl+Shift+B**，划词翻译 **Ctrl+Shift+X**（以设置为准）。

## 一、窄条（Ctrl+Shift+B）——你每天最常用的一面

- **整体观感焕新**：整条变成一块 Win11 式浮层——圆角、单层柔和阴影、半透明
  材质微微透出桌面壁纸。材质跟随你的 Windows 主题深浅。
- **时间一眼可读**：卡片右上角现在是"刚刚 / 3 分钟前 / 昨天 / 3 天前"，
  鼠标悬停时间可看完整日期时间。
- **悬停托盘换成系统图标**：悬停任意卡片，右侧滑出 8-10 个图标（复制/粘贴/
  纯文本/打开/定位/置顶/收藏/备注/归组/删除），即 Win11 设置里的那套系统
  符号字体。**鼠标悬停在图标上有完整提示**：动作名 + 品牌单汉字 + 快捷键
  （如"复制（复 · C）"）。按住 **Ctrl** 依旧让图标就地变成键帽字母。
- **删除不再是一步深渊**：点删除（或选中按 D）后，底部出现
  **"已删除「内容摘要」· 撤销（5 秒）"**——点击"撤销"或按 **Ctrl+Z**，
  这条记录带着它的标签、分组、备注、收藏、置顶原样回来。收藏/置顶条目
  依旧没有删除入口（票 21 保护）。
- **底部一行会说三句话**：平时"共 N 条 · Esc 隐藏"；**有筛选时变成
  "3 / 161 条 · Esc 清除筛选"**（永远知道筛选筛掉多少）；动作后短暂显示
  "已复制"等反馈。

## 二、翻译面板（划词 / Ctrl+Shift+X）

- 译文超长时**面板内滚动**：新译文自动跟随到底，你往上翻阅时不会被拽走。
- **存入历史**成功后按钮就地变成"✓ 已存入"，不再弹系统通知打断。
- 每条存入的译文在窄条里带"译"标，并关联原文条目（票 29）。

## 三、管理窗（托盘 → 历史）

- 工具栏新增**"撤销删除"**：删除条目后 5 秒内可点（或直接按说明操作）；
  被删图片的原图文件也会在撤销时完整恢复。
- **批量翻译运行期间**，删除/清空/置顶/加去标签自动禁用，防止你误改正在
  被读取的数据；结束后自动恢复。
- 列表仍是完整历史（搜索/类型/日期/标签/子类型筛选与批量动作不变）。

## 四、设置窗

- **主题**：三段式开关（跟随系统/浅色/深色），选中的一段以强调色填充——
  与 Windows 11 的分段控件同款交互；悬停未选中项有轻量反馈。
- **删除保护**：主开关 + 保护收藏/保护置顶两个子项；说明文字完整显示在
  开关下方。
- **数据位置**：路径输入框现在随窗口伸展，浏览按钮固定右侧。
- **磁盘占用**：实测显示数据库/图片原图/合计，一键打开数据文件夹。
- 顶部**搜索设置**支持大白话（"多久删""夜间模式""误删"），点结果直接
  跳到那一项并高亮脉冲（票 23）。

## 五、已知变化与注意

1. 窄条呼出后**出现在光标旁**（可在设置·界面关掉"光标旁呼出"回到固定
   位置）；本次修复了它偶尔底部伸出屏幕的问题。
2. 字号整体微调（提示类 11→12，正文大 15→16），对齐 Windows 11 字阶；
   若觉得密度变化明显，可在设置·界面调"文本行数"。
3. 卡片上的图片与图片文件预览现在**行高固定**，列表滚动节奏更稳。
4. 管理窗/设置窗目前是圆角 + 深色标题栏（Mica 材质需无边框重写，已立项
   后续票）；右键菜单保持不透明以保证可读性。
5. 全部 466 项自动化测试与实机探针通过；快捷键、分组、翻译、备份、
   轻量模式行为与之前一致。

## 六、一句话验收

呼出窄条看一眼新外壳 → 悬停卡片认一认新图标（tooltip 有汉字+快捷键）→
删一条试试 5 秒撤销 → 划词翻译一条点"存入历史"→ 到设置·数据看看磁盘
占用。四步走完，这轮改造就验收完了。
