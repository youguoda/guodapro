## 三、发现并修复的缺陷（截图探针驱动）

1. **窄条底部伸出工作区 280px**（被任务栏截断）。三层根因：首次召唤时
   `PresentationSource` 为 null → DPI scale 静默回退 1.0 → `BadgePlacement`
   收到 DIU 尺寸而不翻转/钳制。修复：新增 `ScreenGeometry.ScaleAt`
   （GetDpiForMonitor/Shcore，按光标所在屏取真实 scale，不依赖 WPF 句柄），
   且尺寸改用声明的 Width/Height（未布局时 Actual 全为 0）。
2. **托盘字形全部 tofu**：`Content=字符串` 时 ContentPresenter 生成的
   TextBlock 被隐式 `TextBlock` 样式强制成 Font.Ui，符号码位用 UI 字体渲染。
   修复：托盘按钮内容改为显式 TextBlock（Font.Icon），Ctrl 键帽切换时同步
   切回 Font.Ui。
3. **AccentHover 白字对比度 4.49 < AA 4.5**：令牌测试拦下，色值调深
   （#FF2A6FD8）。
4. **删除保护勾选框吞超长 Hint**：文案作为 checkbox 内容被右侧截断。修复：
   ItemEditors.Toggle 的 hint 改为勾选框下方全宽小字。
5. **数据位置输入框不伸展**：横向 StackPanel 内 TextBox 收缩到最小宽度。
   修复：改两列 Grid（* + Auto）。

   搁浅判定原先只对照**主屏**工作区——合法住在副屏的窄条每次重启都被拽回
   主屏。改为对照**虚拟桌面全域**判定，副屏驻留合法。
3. **跨屏一致性说明**：拾语是 PerMonitorV2 应用，尺寸以设备无关单位存储，
   两块屏各自按系统缩放换算——物理大小是否一致由 Windows 的缩放设置决定。
   建议：4K 屏用 150%、2K 屏用 100%（同尺寸面板时两者 ppi 接近，观感即
   一致）；若仍觉差异，可在"设置→系统→屏幕"分别微调两屏缩放比例。
