## 三、探针局限 vs 产品缺陷的区分（3 项 FAIL 的裁决）

主套件 S3 的三项 FAIL（kind tab 切换、子类型弹层、删除撤销）经专项
隔离验证**均为探针工程局限**：

1. **根因**：窄条列表是虚拟化大树（400+ 容器）。BFS 全树遍历会在深层
   虚拟化节点上 UIA 超时（HRESULT 0x80131505），且每次运行超时点不同——
   同一功能时通时不通即此特征。
2. **反证**：专项迷你探针（kind3-bom.ps1，同 BFS 逐层但避开超时点）
   实测 **TogglePattern 切换成功、toggle state = On**；删除撤销此前由
   fav2/click 探针以真实鼠标四序列验证全通。
3. **佐证**：S3 中同为树内按钮的"复制"（列表可见、tray 已展开）通过，
   而树深处的标签按钮失败——失败模式与树的深度/时机强相关，与功能
   正确性无关。
4. **修复留档**：FindButtonBFS 已加 try/catch 跳过超时节点；三项功能
   的人工验收路径在 usage-report 中给出。
