## 1. 翻译健壮性（票 34）

- [ ] **方向标签**：划词翻译一段中文（Ctrl+Shift+Z）→ 面板顶部方向标签应显示检测到的
      语言名（如"中文"），不再是"自动识别"
- [ ] **回声换向**：目标语言设为 Chinese 的情况下翻译一段中文 → 应自动换向输出英文
      （标签会显示实际在途方向）；重试仍回声时如实展示，不死循环
- [ ] **人话报错**：设置里把服务地址改错再翻译 → 应得"凭据无效/连接失败"类人话，
      不是裸异常；改回即恢复
- [ ] （可选）限流场景：连续快速大量翻译 → 最多静默退避两次后报错，面板不卡死

## 2. 词典卡 · 逐句对照 · 朗读（票 35）

- [ ] **单词卡**：划词翻译英文单词（如 serendipity / ephemeral）→ 卡片先出译文，
      ~600ms 内下方补出音标/词性/释义/例句/同义词；换个生僻词再试
- [ ] **词典静默**：断网状态下翻译英文单词 → 译文照出（走 LLM），词典部分安静缺席
      不报错
- [ ] **逐句对照**：翻译两三个句子的段落 → 点面板上的「逐句对照」按钮 → 原文/译文
      逐句成对显示；再点回整段流式
- [ ] **朗读**：点译文旁 🔊 → 出声；再点 → 停；换向（中↔英）后朗读音色跟随语言

## 3. 公共翻译通道（票 36）——默认端点尚未部署

- [ ] **现状确认**：设置→服务→"翻译方式"选**公共通道（免费额度）**→ 翻译 → 当前
      应得"连接公共通道失败"类人话降级（官方 Worker 未部署，这是预期行为）
- [ ] **启用公共通道（可选，想测就先部署）**：按 `server/README.md` 走——
      `npm i -g wrangler` → `wrangler login` → 建 KV + `wrangler secret put
      ZHIPU_API_KEY` / `IP_HASH_SALT` → `wrangler deploy` → 把得到的 workers.dev
      地址填进设置的通道端点 → 翻译应出词；把一段文本刷到超 2 万字/天 → 应得带
      剩余额度与重置时间的 429 人话
- [ ] **隐私披露**：切换翻译方式时设置页的披露文案可见（"被翻译的文本会经中转
      发给模型服务；剪贴板历史本身仍不出机器"）
- [ ] 默认仍是自备密钥——不部署也不影响其它一切功能

## 5. 划词徽章（票 37）——默认关

- [ ] **开启**：设置→快捷键→「拖选后出翻译徽标」打开（保存）——注意此开关的说明
      文案写了全局鼠标钩子的开销，是刻意默认关的
- [ ] **正路径**：在浏览器/Word/记事本里拖选一段文字 → 光标旁浮「译 翻译这段」
      徽标 → 点击 → 翻译面板出词（英文单词会带词典卡）
- [ ] **剪贴板还原**：翻译面板出来后按 Ctrl+V → 粘出的应是取词前你自己复制的
      内容（还原发生在面板显示之后）
- [ ] **负路径**：桌面空白处拖选不出徽标；选中 `C:\Windows\System32` 这类路径
      形不出；纯数字不出
- [ ] **关即摘钩**：关掉开关 → 拖选立即无反应；退出拾语 → 钩子自动还给系统
